# Accessing the nLCA Tool

## Public web application

The nLCA Tool is available online:

https://nlca-tool.onrender.com/

Users can access the hosted application
through a compatible web browser.

No local installation is required to
access the hosted version.

## Source code availability

This public repository provides documentation
and scientific figures.

It is not a distribution of the underlying
application source code.
